# Truthfulness Despite Weak Supervision: Evaluating and Training LLMs Using Peer Prediction

This anonymized repository contains the code for the paper "Truthfulness Despite Weak Supervision: Evaluating and Training LLMs Using Peer Prediction".

Prepare the environment by running:

```bash
pip install -r requirements.txt
```

Any Python 3.8+ environment should be able to run the code.

You may refer to `results/` for relevant data files.

### Replication Instructions: Deception Experiments

```bash
PREDICTOR_MODEL_ID=6 NUM_MODELS=4 NUM_DECEPTIVE_MODELS=1 python3 ./run_experiment_deceptivewitness.py
```

This command will run the deception experiment with 4 models, 1 of which is deceptive. It will produce multiple json files in the `./results` directory, containing both responses and peer predictions. It will also produce a `sorted_reports.json` file in the `./results` directory, which, for each question, ranks the models by peer prediction score.

Here is the list of "predictor model" (i.e. juror models) IDs (from 1 to 6):
1. Qwen2.5-7B-Instruct
2. Qwen2.5-3B-Instruct
3. Qwen2.5-1.5B-Instruct
4. Qwen2.5-0.5B-Instruct
5. SmolLM-360M-Instruct
6. SmolLM-135M-Instruct

To achieve 100% reproduction, you could run `remove_caveats.py` to remove rare caveats from the deceptive responses before rerunning the experiment.

You could also specify the participant model, for example:

```bash
PREDICTOR_MODEL_ID=6 NUM_MODELS=4 NUM_DECEPTIVE_MODELS=1 BASE_MODEL=mistral-7b python3 ./run_experiment_deceptivewitness.py
```

You could similarly obtain the results for LLM-as-a-Judge by running, for example:

```bash
PREDICTOR_MODEL_ID=6 NUM_DECEPTIVE_MODELS=1 NUM_MODELS=4 python3 ./run_experiment_llmasajudge.py
```

Finally, you could aggregate all results by running:

```bash
python3 ./get_data_for_scaling.py
```

And then plot the scaling results by running:

```bash
python3 ./visualize.py
```

You could choose to make other plots by modifying the final line of `visualize.py`.

Many variants of such experiments exist, and you could add extra environmental variables to the command line to specify them. See the code you are running for more details about the available options. Specifically, you could enable the mixed setting (Llama + Mistral + Gemma as participants) by setting `MIXED=1` (6 models in total, 3 deceptive) or `MIXED=2` (4 models in total, 1 deceptive). You could also enable the use of MisleadLM as an alternative deceptive model by setting `MISLEAD=1`, but this needs to be used in conjunction with `pretrain_to_instruction.py` and `transform_cases.py`.

You could find the original resultsfor the main deception experiments, but the variants are not included due to Anonymous Github's storage limit; large data files have been compressed to save space. The remaining data can be generated by running the code in this repository, and is also available upon request.

### Replication Instructions: Effectiveness Experiments

```bash
python3 ./run_experiment_allhonest.py
```

This command will run the effectiveness experiment with Llama 3.1 8B/70B/405B as participants and Mistral 7B v0.3 as the juror. It will produce multiple json files in the `./results` directory, containing both responses and peer predictions. It will also produce a `sorted_reports.json` file in the `./results` directory, which, for each question, ranks the models by peer prediction score.

You could also plot the results by running:

```bash
python3 ./visualize.py
```

... after changing the final line of `visualize.py` to `draw_value_curves_subplots()`. You could choose to make other plots by modifying the final line of `visualize.py` to call one of the other plotting functions.

Again, variants of such experiments exist, and you could add extra environmental variables to the command line to specify them. See the code you are running for more details about the available options.

You could find the original data for the effectiveness experiment in the `./results` directory of this repository.
